# Physics-module tool template

Starting point for a physics module that fits the tool registry — i.e.
a model whose surface is small enough that it doesn't need its own
versioned `packages/physics_modules/<domain>/<name>/` tree.

If your model is a full physics module (validated test suite, validity
domain document, equations document, multiple versions), use
`packages/physics_modules/templates/<closest>/` instead and follow the
plan §14 module workflow.
